Anadolu Qida — ein klareres Zuhause für einen Mehlproduzenten.

Markengeführtes Webdesign und Entwicklung für einen Mehlproduzenten aus Baku: klare Produkte, eine greifbare Produktionsgeschichte und ein direkter Weg für Geschäftsanfragen.

Die Arbeit übersetzte den Produktionsbetrieb in einen glaubwürdigen digitalen Auftritt — damit Käufer und Partner das Angebot verstehen, dem Unternehmen vertrauen und unkompliziert eine Bestellung anfragen können.

Kunde
Anadolu Qida
Leistung
Strategie, UI/UX, Entwicklung
Dauer
Ca. vier Wochen
Status
Live auf anadoluqida.com

01 / Kontext

Ein Produktionsbetrieb brauchte eine Website, so solide wie die Fabrik.

Anadolu Qida produziert Mehl für Bäckereien, Teigküchen und Großkunden. Der digitale Auftritt musste Verpackungen klar zeigen, die Produktion erklären und ernsthafte Käufer zur Anfrage führen — während Mirvari Logistics aus demselben System erreichbar bleibt.

02 / Lösung

Ein redaktionelles System für Produkte, Werte und Bestellungen.

Das Interface stellt die Fakten zum Produkt an erste Stelle: Packungsgrößen, Einsatzbereiche und Produktionskontrolle. Ausdrucksstarke Fotografie trägt die Identität, zurückhaltende Typografie den kommerziellen Weg. Werte, Katalog und Anfrage folgen einer Hierarchie.

Die Produktfotografie ist auf Hochformat ausgelegt — das Layout respektiert die Proportionen der Verpackungen, statt alles in Querformate zu zwingen.

03 / Ergebnis

Eine veröffentlichte Unternehmenswebsite, klar strukturiert und bereit für Anfragen.

Mehlprodukte, Produktionsgeschichte, Zertifikate und Bestellkontakt — mit Mirvari Logistics über einen bewussten Markenwechsel verbunden. Das Ergebnis ist live auf anadoluqida.com.

Live-Website ansehen.
